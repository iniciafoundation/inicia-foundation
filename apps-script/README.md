# Google-таблица для сайта (заявки, новости, сборы)

Скрипт `Code.gs` принимает заявки из форм сайта, сохраняет их в Google-таблицу, присылает письмо на direccion@iniciafoundation.org и отправляет человеку автоответ на его языке. Из той же таблицы сайт берёт новости, суммы сборов по проектам и мероприятия.

## Подключение (один раз, ~5 минут)

Всё делается под аккаунтом **direccion@iniciafoundation.org**.

1. Откройте https://script.google.com → **Новый проект** (New project).
2. Удалите пример кода, вставьте всё содержимое файла `Code.gs`, нажмите 💾 (Сохранить). Назовите проект «INICIA Web».
3. Вверху в списке функций выберите **setup** → **Выполнить** (Run).
4. Google попросит разрешения → **Проверить разрешения** → выберите аккаунт direccion@ → **Разрешить**. Если появится «Приложение не проверено» — **Дополнительно → Перейти к INICIA Web**.
5. Внизу в журнале появится ссылка на новую таблицу «INICIA — Web: solicitudes y contenido». Она лежит на вашем Google Диске.
6. Нажмите **Начать развёртывание → Новое развёртывание** (Deploy → New deployment) → шестерёнка → **Веб-приложение** (Web app):
   - Описание: «Web INICIA»
   - Запуск от имени: **Я** (Me)
   - Доступ: **Все** (Anyone)
   → **Развернуть** (Deploy).
7. Скопируйте **URL веб-приложения** (заканчивается на `/exec`) и пришлите его Claude — он вставит его в `client/src/lib/siteConfig.ts` (`SHEETS_ENDPOINT`).

Пока адрес не вставлен, формы сайта отправляют заявки в старый ящик Formspree, а блоки новостей и сборов скрыты.

## Как пользоваться таблицей

**Вкладки заявок** — Ayuda, Voluntariado, Organizaciones, Donaciones y socios, Otras consultas:
- колонка **estado**: Nueva → En curso → Cerrada;
- **responsable** — кто ведёт; **notas** — заметки.

**Noticias** — новости на сайте:
- одна строка = одна новость на одном языке (`idioma`: es / en / ru / uk, или «todos» для всех языков);
- `imagen` — ссылка на картинку; можно ссылку Google Диска (файл должен быть открыт «всем, у кого есть ссылка»);
- `proyecto` — необязательно, название проекта;
- поставьте галочку **publicar**, и новость появится на сайте в течение 5 минут.

**Recaudacion** — сборы по проектам:
- `proyecto` — адрес проекта на сайте (например, для `iniciafoundation.org/proyectos/nucleo` пишите `nucleo`);
- `objetivo` — цель в евро, `recaudado` — собрано, `donantes` — сколько человек;
- `nota_es / nota_en / nota_ru / nota_uk` — на что пойдут деньги;
- галочка **activo** показывает полосу сбора на странице проекта.

**Eventos** — мероприятия: дата, время, название, место, ссылка; галочка **publicar**. Прошедшие скрываются сами.

**Asistente** — вопросы и ответы для помощника «Pregúntanos» на сайте: `idioma` (es/en/ru/uk или todos), `pregunta`, `palabras_clave` (слова, по которым его найти), `respuesta`, `enlace` (необязательно, например /donar). Галочка **publicar** — показать.

**Ajustes** — настройки сайта без новой публикации (0 кредитов Netlify). Колонка `valor`:
- `social_*` — ссылки на соцсети (Facebook, Instagram, LinkedIn, YouTube, TikTok, X, Telegram, канал WhatsApp, Threads, Bluesky). Пустое значение — иконки на сайте нет.
- `pago_bizum_codigo` — код Bizum ONG от банка; появится вкладка Bizum.
- `pago_tarjeta_enlace` — ссылка оплаты картой / Apple Pay / Google Pay (Stripe Payment Link или TPV банка); появится вкладка «Карта» с QR-кодом.
- `pago_paypal_enlace`, `pago_teaming_enlace`, `pago_otro_nombre` + `pago_otro_enlace` — другие способы.
- `video_inicio_youtube` — ссылка на видео YouTube для главной страницы.
- `analitica_ga4` (G-…) и `google_ads_conversion` (AW-…/метка) — включают баннер cookie и измерение конверсий для Google Ad Grants.
- `aviso_banner` — короткий текст жёлтой полосы вверху сайта.
Принимаются только ссылки, начинающиеся с https://.

Чтобы изменения появились сразу, а не через 5 минут: в редакторе скрипта выберите функцию **refreshContent** → Выполнить.

## Безопасность

- Таблица доступна только вам. Делитесь ею только с теми, кто обрабатывает заявки.
- Включите двухэтапную проверку для direccion@.
- Форма не собирает номера счетов и медицинские данные.
- Если изменили `Code.gs`, сделайте **Развернуть → Управление развёртываниями → ✏️ → Версия: новая** — адрес останется прежним.
